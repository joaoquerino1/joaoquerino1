👨‍💻 Sobre mim

Oi! Sou o João Victor Querino Morais, estudante de Análise e Desenvolvimento de Sistemas e desenvolvedor Full Stack em formação, com foco especial em back-end, APIs REST, bancos de dados e desenvolvimento de aplicações web.

Tenho construído minha experiência através de projetos práticos utilizando diferentes tecnologias e buscando evoluir não apenas na escrita de código, mas também em arquitetura, organização, boas práticas, integração entre sistemas e deploy.

Atualmente, meu foco está principalmente no ecossistema Java + Spring Boot e Python + FastAPI para back-end, complementado por Angular, React, Next.js e TypeScript no desenvolvimento front-end.

* 🚀 Desenvolvendo aplicações Full Stack com forte foco em back-end
* ⚙️ Desenvolvendo APIs REST com Java/Spring Boot e Python/FastAPI
* 🗄️ Trabalhando com PostgreSQL, SQLite, JPA/Hibernate e SQL
* 🎯 Estudando arquitetura, segurança, testes e boas práticas de desenvolvimento
* 🐳 Utilizando Docker e explorando CI/CD e ambientes de deploy
* 💡 Motivado a transformar problemas reais em soluções através da tecnologia
* 📍 São José, Santa Catarina, Brasil

🚀 Projeto em Destaque - Bravial

Bravial

Aplicação Full Stack desenvolvida com backend em Java/Spring Boot e frontend em Angular, trabalhando com persistência de dados, banco PostgreSQL, migrations e containerização.

O projeto representa uma evolução importante nos meus estudos de desenvolvimento de software, aproximando o desenvolvimento acadêmico de uma aplicação estruturada para um cenário real.

Tecnologias utilizadas:

* Java
* Spring Boot
* Angular
* TypeScript
* PostgreSQL
* Spring Data JPA
* Flyway
* Docker
* Railway
* Git & GitHub

💡 Projeto desenvolvido com foco em arquitetura Full Stack, desenvolvimento de APIs, persistência de dados, organização do código e deploy.
