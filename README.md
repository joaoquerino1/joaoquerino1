### Rei do Outlet

Protótipo de modernização digital para uma loja de móveis, desenvolvido com foco em performance, experiência do usuário e escalabilidade.

**Tecnologias utilizadas:**

- Next.js
- React
- TypeScript
- Tailwind CSS
